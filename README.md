# Image Search App

A JavaScript web application for searching photos via the Pixabay API.
Demonstrates asynchronous requests, dynamic DOM rendering, infinite scroll, and
modal previews.

📌 Features

- **Image Search:** Fetch high-resolution images using the Pixabay API.
- **Infinite Scroll:** Automatic loading of search results via
  `IntersectionObserver`.
- **Lightbox Preview:** Full-screen modal previews powered by `SimpleLightbox`.
- **Notifications:** Real-time feedback for search results and edge cases using
  `Notiflix`.

🛠️ Built With

- **HTML5 / CSS3**
- **Vanilla JavaScript (ES6+)**
- **Axios**, **SimpleLightbox**, **Notiflix**
- **Parcel** (web application bundler)

💻 How to Run

1. Clone the repository: `git clone <repository-url>`
2. Install dependencies: `npm install`
3. Start dev server: `npm start`
